# Shop drawing thép sàn

Bản mã nguồn tiện ích shop thép sàn (lưu kèm repo Website).

- **Chạy live:** https://ntgiahuy.github.io/san/
- **Repo triển khai:** https://github.com/ntgiahuy/san

## Chạy local

```bash
cd san-app
npm install
npm run dev
```

Mở `/san/` trên cổng dev. Xuất site tĩnh: `npm run build` → thư mục `out/`.

Hub Website **chưa** nhúng app này (vẫn “Sắp ra mắt”); mã chỉ được lưu tại đây để đồng bộ / bảo trì.
